# v1.7.0 Release Review

This record covers the removal of the retired v0.6 JavaScript product implementation, the migration of
active repository tooling to strict TypeScript, and the addition of the preferred `agentobs` command while
retaining `agent-observability` compatibility.

## Final verdict

- **Approved for merge:** exact-head local validation, GitHub CI, and role-separated code and documentation
  reviews passed.
- **Reviewed source:** `935a425ca4ea8d062d296c5521295e79b0926ef1`.
- **Base:** v1.6.0 publication merge `a3fc152a49744a9e0c64dfe8155ea9ce4fd74106`.
- **Publication:** completed from merge commit `d1e639f8152e902a0f14ebcdefcfdd2aa643963c`.

## Delivered scope

- The retired v0.6 JavaScript product tree was removed after Rust parity. Compatibility fixtures remain only
  where they verify migrations from earlier releases.
- Active build, release, browser smoke, and regression scripts are strict TypeScript. A source audit rejects
  authored `.js`, `.mjs`, and `.cjs` product files while allowing the exact generated browser artifacts that
  are rebuilt from TypeScript.
- The npm package and macOS installer expose both `agentobs` and `agent-observability`. `agentobs` is the
  preferred command; the long name remains compatible with existing automation.
- `agentobs dashboard` generates and opens the local monitoring report. `agentobs ui` opens the local runtime
  settings application.
- Installer publication is transactional across both command names: unmanaged collisions fail closed, and a
  failed alias publication restores the previous primary command and alias.
- Release CI installs the assembled npm tarball into an isolated prefix and executes both aliases before any
  package or Release publication.
