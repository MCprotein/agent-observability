# v0.6.1 Independent Review

PR #1 was reviewed independently by the `test-engineer` and `code-reviewer`
roles before merge.

## Blocking findings resolved

- Private artifact directories must use `0700` and files use `0600`; permissive
  caller-owned directories are rejected without changing their permissions.
- Permission events without source-provided IDs require a stable source cursor;
  unstable identities are rejected instead of collapsing or changing on replay.
- Replay comparison is structural, so object key insertion order does not create
  a false identity conflict.
- Batch replay conflicts are validated before any new record in that batch is
  appended.
- Adapter IDs use collision-safe tuple encoding and conflicting duplicate leaf
  events fail instead of being silently discarded.
- Single-record append uses the same replay contract as batch append.
- Existing v1 records pass through a strict compatibility projection, while raw
  status messages and opaque identifiers cannot reach durable or report sinks;
  migrated JSONL is atomically rewritten so discarded legacy bytes do not remain.

Each fix has a focused regression test. The complete JavaScript suite and
privacy scan are required to pass on the reviewed commit.

## Deferred scope

- Cross-process writers, crash-point atomicity, out-of-order topology, and
  interrupted lifecycle reduction belong to the transactional Rust core in
  v0.8.0.
- Additional agent adapters remain assigned to their roadmap versions after the
  canonical Rust contract boundary is established.
