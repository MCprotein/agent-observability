then failed at Package publication. npm interpreted `dist/<package>.tgz` as a GitHub repository
shorthand and attempted to resolve it over SSH. v1.3.2 passes an explicit local path:

```text

```

The exact argument is regression-locked. A fresh release binary and npm tarball were also assembled
from the reviewed source; `npm publish --dry-run` selected
`@mcprotein/agent-observability@1.3.2` from that local tarball.
