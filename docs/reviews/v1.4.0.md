# v1.4.0 Release Review

This record covers the local onboarding and documentation usability release. It adds one-command
demo and setup paths, mutable CLI configuration, explicit dashboard opening, and a README organized
around first observable value while preserving the manual private-handoff boundary.

## Final verdict

- **Approved for merge:** exact-head tests, GitHub CI, macOS opener smoke, and role-separated code
  and documentation reviews passed.
- **Reviewed source:** `bbfc187685fdb3b3222da9b9883c59c42944f01c`.
- **Base:** v1.3.2 publication merge `e3d8113a9d29bfc71b6b3643ecce04b7a47ff5c4`.
- **Publication:** pending merge and annotated `v1.4.0` tag.

## Delivered scope

- `demo` creates a content-free isolated runtime, verifies that observable data exists, writes the
  report, and opens it on macOS unless `--no-open` is selected.
- `setup`, `dashboard`, `config show`, and `config set` provide the primary local workflow without
  requiring a server or account.
- Config replacement uses private collision-resistant temporary files, file and directory sync,
  atomic rename, validation, and explicit pre/post-rename failure semantics.
- README quick start, capability and adapter tables, architecture and retention Mermaid flows, and
  progressive links expose unsupported automatic producer and team boundaries directly.
