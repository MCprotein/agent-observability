# v0.9.0 Independent Review

The experimental Rust Codex adapter release was independently reviewed by the
`architect`, `code-reviewer`, and `test-engineer` roles. All three returned
`APPROVE` after the blocking findings below were resolved.

## Blocking findings resolved

- Bounded handoff parsing now proves exact and over-limit byte, line, record,
  permission, symlink, and regular-file boundaries.
- Tail-only restart and source rotation preserve strict cursor chains. A 7+1
  process split produces byte-identical projection and matching observation and
  disposition counts compared with full-batch ingest.
- Batch-local and cross-batch canonical duplicates use one privacy-safe durable
  projection fingerprint. Replays with changed lifecycle, correlation, token,
  timing, or bounded metadata fail with a payload conflict.
- Observation and disposition cursors share one transactional idempotency
  namespace. Suppression commit, replay, projection repair, and all crash points
  are covered.
- Arbitrary model, tool, decision, prompt, output, path, and error strings do
  not cross the durable boundary. Models use a checked capability allowlist,
  tools use canonical categories, and permissions use a fixed decision enum.
- Existing `local_state.v1` observations, cursors, records, outcomes, and
  projection recovery survive the transactional `local_state.v2` migration.
- Dangling and resolved projection symlinks fail closed.

## Verification

- Rust workspace: 78 tests passed.
- JavaScript migration baseline: 45 tests passed.
- `cargo fmt --all -- --check` passed.
- `cargo clippy --workspace --all-targets --locked -- -D warnings` passed.
- `git diff --check`, fixture hashes, privacy/vendor scans, and the disabled
  team/network boundary checks passed.

## Deferred scope

- Native OTLP HTTP/gRPC receiver and foreground notify spool production remain
  outside v0.9.
- Cross-version, OS, profile, deadline, and load evidence remain required before
  the Codex capability can move from `experimental` to `supported`.
- Rust Claude Code and Cursor adapters remain assigned to v0.10 and v0.11.
- Performance budgets remain assigned to the v0.13 local release candidate.
