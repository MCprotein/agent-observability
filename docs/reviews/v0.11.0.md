# v0.11.0 Independent Review

The experimental Rust Cursor adapter release was independently reviewed by the
`architect`, `code-reviewer`, and `test-engineer` roles. The final verdicts were
`CLEAR`, `APPROVE`, and `APPROVE` for implementation commit `a77df5f` after the
blocking findings below were resolved.

## Blocking findings resolved

- Cursor Hook v1 session reasons use the documented closed values. Unknown model
  slugs preserve lifecycle observations without claiming a normalized model.
- Generic tool hooks own correlated operations. Specific shell, MCP, and file
  hooks without a shared operation identifier become bounded diagnostics instead
  of creating duplicate tool spans.
- A generic pre/post pair shares one stable span. Append-only source observations
  reduce to one current durable/report record whose phase is derived from the
  reduced lifecycle.
- Tool names normalize to the bounded `shell`, `mcp`, `file`, `agent`, or `other`
  categories. Raw email, workspace paths, commands, prompts, output, edits, and
  MCP payloads never cross the adapter or durable projection boundary.
- The private handoff reader validates regular-file identity, private permissions,
  stable post-open metadata, exact byte and line bounds, UTF-8, and symlink
  rejection. Generation rotation uses an independent cursor scope.
- Cursor-specific crash tests cover the same tool span across before/after commit
  and projection-rename boundaries. Reopen and retry retain one current failed
  record with the original start and final end timing.
- Full ingest, split restart, and replay produce identical projections. CLI tests
  fix tool cardinality and the final shell phase, status, timing, and call identity.

## Verification

- Rust workspace: 105 tests passed.
- JavaScript migration baseline: 45 tests passed.
- `cargo fmt --all -- --check` passed.
- `cargo clippy --workspace --all-targets --locked -- -D warnings` passed.
- `git diff --check`, fixture hashes, privacy/legal scans, and the disabled
  team/network boundary checks passed.

## Deferred scope

- Native OTLP HTTP/gRPC receiver and foreground handoff producer remain outside
  v0.11.
- Cursor-specific hooks without a documented shared correlation key remain
  diagnostic-only; non-Unix, cross-version, deadline, and load evidence remain
  explicit experimental capability gaps.
- TypeScript static report UI remains assigned to v0.12.
- Performance budgets remain assigned to the v0.13 local release candidate.
