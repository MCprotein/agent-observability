## Correction

Tag workflow run `33412746641` built both v1.3.0 native artifacts, then failed before attestation,
Release creation, or Package publication. The workflow passed the input file after
`lipo -verify_arch`; Xcode `lipo` requires the input file first. v1.3.1 uses:

```bash
lipo stage/agent-observability -verify_arch arm64 x86_64
```

The workflow text is regression-locked. More importantly, the arm64 and x64 artifacts from failed
run `33412746641` were downloaded, combined locally, and checked with that exact corrected command;
`lipo -archs` reported `x86_64 arm64`, and the universal executable reported version `1.3.0`.
The v1.3.1 tag workflow rebuilds the same source path at version `1.3.1` and executes this check
before attestation or publication.
