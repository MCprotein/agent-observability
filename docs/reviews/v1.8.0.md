# v1.8.0 Release Review Draft

Status: **In Progress**. This draft records the implemented Codex automatic local collection slice and the
evidence still required before v1.8.0 can be marked `Released`.

## Review scope

- Add optional macOS Codex automatic collection through an authenticated `127.0.0.1` OTLP/HTTP JSON receiver.
- Use `agent-turn-complete` notify only as a bounded, fail-open turn-completion supplement.
- Install and remove a runtime-root-specific LaunchAgent.
- Own only the required Codex config values and restore the exact pre-connect bytes and mode on disconnect.
- Preserve Codex, Claude Code and Cursor manual private handoff imports without daemon, login or network.
- Keep all external/team transport disabled.

## Implemented boundary

- `agentobs setup` prepares the default runtime, connects Codex automatic collection and opens the private
  dashboard. `connect codex`, `status codex` and `disconnect codex` expose the lifecycle separately.
- The authenticated ephemeral settings UI exposes the same integration lifecycle and can open the existing
  private report without becoming the collector process itself.
- The receiver binds only IPv4 loopback and requires a private token for health, OTLP logs and notify requests.
- OTLP/HTTP JSON requests are bounded to 1 MiB and 4096 log records. Notify payloads are bounded to 64 KiB and
  use local connect/read/write deadlines before returning a fail-open outcome.
- Raw OTLP, notify and tool fields may exist transiently in process memory during bounded decode. Only
  explicitly allowlisted scalars cross the Codex adapter. Raw prompt/response, tool arguments/output, command,
  cwd, path, account identity and unknown fields are not persisted, logged, placed in diagnostics, projected,
  reported, archived or exported.
- Source-ordered observations and content-free dispositions use one SQLite transaction. A durable private dirty
  marker drives bounded report refresh and startup recovery for `<root>/logs/agent-observability-report.html`.
- Disconnect confirms LaunchAgent termination before restoring exact prior Codex config bytes/mode or removing a
  config created by connect. The complete current bytes/mode must match the recorded connected state; any
  intervening edit fails closed and remains untouched. Local observations remain.

## Explicit non-goals

- Claude Code automatic collection
- Cursor automatic collection
- OTLP/gRPC
- Agent file, credential, browser-session or private-API scraping
- Any external network destination
- Commercial team collection, query or hosted UI

The local Codex receiver is not team infrastructure. Commercial team cannot be called complete or released
before the G0-G4 approvals and evidence in `docs/TEAM_ARCHITECTURE.md` and `docs/TEAM_CONTRACTS.md` pass.
