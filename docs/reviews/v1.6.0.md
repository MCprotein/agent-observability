# v1.6.0 Release Review

This record covers the integrity-checked one-command macOS installer. It installs the universal binary,
preserves existing private directory and shell-profile permissions, and registers the selected binary
directory in the active shell profile without requiring manual PATH editing.

## Final verdict

- **Approved for merge:** exact-head installer fixtures, full local tests, GitHub CI, and role-separated
  code and documentation reviews passed.
- **Reviewed source:** `8194060626b0b3a8f395147b0801e7733e0b9190`.
- **Base:** v1.5.0 publication merge `52a4e21371911a8cbdd898653208e41c84b166f2`.
- **Publication:** completed from merge commit `259ea5a4cb70a1cf36ad825a5e51fd1d2b3be47c`.

## Delivered scope

- The release-hosted POSIX installer resolves the latest semantic version or accepts an explicit version,
  downloads the universal archive and `SHA256SUMS`, checks archive integrity, and verifies the executable
  version before installation.
- The binary is atomically installed into `~/.local/bin` by default. Existing private directory modes are
  preserved instead of being widened.
- A bounded managed PATH block is added or replaced in `.zshrc`, `.bash_profile`, `.profile`, or an explicit
  profile. Existing content, file mode, and profile symlinks are preserved through a same-directory atomic
  replacement.
- Reinstall is idempotent, install-directory migration replaces the managed block, and malformed, duplicate,
  incomplete, or reversed markers fail closed.
- The release workflow includes `install.sh` in the universal archive and is configured to publish it as a
  checksummed, attested Release asset. The installer checks download integrity; repository/workflow provenance
  remains a separately verifiable GitHub artifact attestation after publication.
- The release workflow runs the assembled installer against the final universal archive and checksum on macOS
  before attestation and publication.
