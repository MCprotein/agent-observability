# v1.3.0 Release Review

This record captures the completed review and verification for the installable open-source
distribution release. The release changes licensing, packaging, publication, and onboarding; it
does not add a receiver, producer, daemon, login, collector, hosted UI, or network path.

## Final verdict

- **Superseded before publication:** required local checks, exact-head GitHub CI, and
  role-separated review passed, but tag workflow run `33412746641` failed during universal-binary
  assembly before attestation, Release creation, or Package publication.
- **Reviewed source:** `bcd18ce638c26b17c7c0ea1e919c7fc6b553ee9b`.
- **License:** repository and package metadata use Apache-2.0; `LICENSE` byte-matches the official
  Apache License 2.0 text.
- **Distribution:** the tag workflow builds macOS arm64 and x64 Rust binaries, assembles a
  universal2 binary, publishes checksummed archives and provenance through GitHub Releases, and
  publishes the same native executable through GitHub Packages.
- **Boundary:** npm is transport metadata only. The package has no JavaScript launcher, scripts,
  dependencies, daemon, collector, or network runtime.

## Findings resolved

- Release-critical actions are pinned to reviewed full commit SHAs instead of mutable major tags.
- Node 20 is selected before package assembly, removing runner-image Node/npm drift.
- Package lookup distinguishes explicit `E404` absence from authentication, authorization, and
  network failures. Only explicit absence enters publication.
- Draft creation/upload, already-published retries, package publish/skip, lookup failure, and
  finalization are explicit state transitions with command-order regression tests.
- Fresh macOS installation creates `~/.local/bin` and exports it into the current shell `PATH`.
- Release archives and the package contain a content-free canonical handoff example that exercises
  ingest and self-contained report generation without claiming that a producer is shipped.
- README Mermaid blocks were replaced with renderer-independent text diagrams.
